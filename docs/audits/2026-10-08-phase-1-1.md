## Implementación inspeccionada
- UI Compose y modos de layout; importación PDF/DOCX/TXT mediante OpenDocument.
- PDFBox extracción textual lee todo el archivo con `readBytes()`: riesgo de memoria con archivos grandes.
- DOCX propio extrae `word/document.xml` por párrafos, sin soporte explícito de fórmulas OMML.
- BookSessionStore usa SharedPreferences para último libro y offsets; no es todavía biblioteca persistente multilibro.
- OfflineNeuralVoiceRenderer implementa modelos locales Piper (es_ES miro, es_AR daniela) con caché WAV y reutilización de caché antigua; serializa render vía Mutex.
- NarrationPlaybackService usa ExoPlayer/MediaSessionService y cola con pre-generación; funcionamiento real y ausencia de pausas no comprobados.
- CrashReporter evita deliberadamente recopilar título, texto o URI; integración opcional cuando existe configuración Firebase.
